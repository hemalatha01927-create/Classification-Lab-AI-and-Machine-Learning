# Classification Lab – AI & Machine Learning

A beginner-friendly, single-page learning tool for seeing how a k-nearest-neighbors classifier relates study habits to sample support outcomes.

## Run locally in VS Code

1. Open the `artifacts/classification-lab` folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**.

The model, dataset editing, evaluation, and predictions run in the browser; no backend, API key, or paid service is required. Chart.js and the optional fonts are loaded from public CDNs, so an internet connection is needed for charts and the intended typography. If Chart.js cannot load, the app displays an explanation while dataset, training, evaluation numbers, and prediction logic remain local.

To run this artifact inside the Replit workspace instead, start its configured web preview.

## What is included

- Dashboard totals, actual held-out accuracy or a clear not-trained state, class pattern chart, and recent predictions.
- Searchable sample-data table; add validated examples and delete individual records.
- Deterministic, stratified 75/25 train/test split per class.
- Euclidean k-NN over three z-score-normalized features. Means and standard deviations are fitted only on the training partition; held-out rows are never used as neighbors.
- Adjustable, bounds-checked k; changing k recalculates evaluation against the same held-out set.
- Accuracy, precision, recall, F1, a confusion matrix, and actual-versus-predicted counts. “Needs Support” is the consistently defined positive class. A zero denominator yields a safe 0 metric.
- Validated local predictions with exact neighbor-vote share and a plain-language explanation.
- Dataset edits invalidate the fitted model and its metrics. Train again before evaluating or predicting.
- Records, k, and recent predictions are saved in this browser's localStorage where available. The trained model is deliberately not persisted.

## Educational data notice

The seeded, balanced records are synthetic examples generated by a deterministic local routine. They are not real student records and should not be used to make decisions about actual learners. Added records are also demonstration data. This tool illustrates a basic algorithm and does not establish causation, fairness, or educational suitability.

## File guide

- `index.html` – accessible document shell and Chart.js CDN.
- `style.css` – responsive white, purple, blue, and teal interface.
- `script.js` – sample data, validation, model/split/math, charts, local persistence, and interactions.

## Model notes

For each class, the seeded deterministic shuffle holds out one quarter (at least one when possible) and uses the rest for training. Features are normalized using population standard deviation from training records only. Neighbors are ranked by normalized Euclidean distance, with record ID as a deterministic distance-tie breaker. If the neighbor vote is tied, “Needs Support” wins the classification tie. Confusion-matrix cells use actual rows and predicted columns.
